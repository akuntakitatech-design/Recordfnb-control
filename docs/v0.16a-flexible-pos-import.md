# v0.16A Flexible POS Import

## Quinos Invoice Detail Report

Flow:

1. Upload `.xls` / `.xlsx`.
2. Detect `Quinos Point Of Sale` + `Invoice Detail Report`.
3. Parse invoice blocks from `Invoice #` column.
4. Normalize invoice metadata (`Cashier`, `Type`, `Opened`, `Closed`).
5. Detect item code/name/quantity/line amount.
6. Detect payment tender (`Cash`, `QRIS`, `Transfer`, `GoFood`, `GrabFood`, `Compliment`).
7. Match external code to system item, with saved item alias fallback.
8. Show parser warnings and unmapped menu count before a batch can be saved.
9. User mapping is saved to the import profile and reused on the next import.

The existing normalized `sales_import_batches` / `sales_import_rows` remain the runtime sales data model. The parser is only an intake layer.
